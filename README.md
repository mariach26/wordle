# Wordle Clone (CustomTkinter)

Ένας desktop κλώνος του **Wordle** φτιαγμένος με **Python** και **CustomTkinter**. Ο παίκτης έχει 5 προσπάθειες για να μαντέψει μια κρυφή λέξη 5 γραμμάτων, λαμβάνοντας χρωματικές ενδείξεις μετά από κάθε προσπάθεια.

## Λειτουργίες

- **Κλασικοί Κανόνες Wordle:** Μάντεψε μια λέξη 5 γραμμάτων μέσα σε 5 προσπάθειες.
- **Χρωματικές Ενδείξεις:**
  - 🟩 **Πράσινο:** Σωστό γράμμα στη σωστή θέση.
  - 🟨 **Κίτρινο:** Σωστό γράμμα σε λάθος θέση (με σωστή διαχείριση διπλών γραμμάτων).
  - ⬜ **Γκρι:** Το γράμμα δεν υπάρχει στη λέξη.
- **Μοντέρνο Desktop UI:** Φτιαγμένο με `customtkinter` για καθαρή εμφάνιση και `CTkMessagebox` για παράθυρα νίκης, ήττας και σφαλμάτων.
- **Υποστήριξη Πληκτρολογίου:** Υποβολή λέξης είτε με το κουμπί **Guess** είτε πατώντας `Enter`.
- **Έλεγχος Εγκυρότητας:** Ειδοποιεί τον χρήστη αν η λέξη που έδωσε δεν έχει ακριβώς 5 χαρακτήρες.

- [Python 3](https://www.python.org/)
